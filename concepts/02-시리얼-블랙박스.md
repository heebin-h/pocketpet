# 시리얼 블랙박스 — 레거시 장비 프린터 포트를 전자기록으로

- 작성일: 2026-11-10
- 대상 보드: Radxa ROCK Pi S (RS308-D4: RK3308, 512MB, 무선 없음, 100M Ethernet) — 제품화 시 eMMC SKU(`RS308-D4E8…`) 또는 Core SoM + 자체 캐리어
- 상태: 컨셉 (미검증)

## 결론

공장·실험실의 구형 장비(전자저울, pH미터, 분석기, 항온항습기, 냉동고 컨트롤러)는 결과를 **RS-232 시리얼 프린터로 출력**하는 경우가 많다. 이 박스가 **프린터인 척** 데이터를 받아 원본 그대로·위변조 감지 가능하게 영구 기록하고, 동시에 웹/엑셀/MQTT로 내보낸다.

**색: "장비는 그대로, 종이만 없앤다."** 장비 교체(수천만 원)나 SW 연동 개발 없이 프린터 케이블 자리에 꽂기만 하면 된다.

---

## 1. 왜 ROCK Pi S인가

| 보드 특성 | 제품에서의 의미 |
|---|---|
| HW UART + USB host | RS-232(레벨변환)·USB-시리얼로 다포트 수집. 연산은 거의 불필요 |
| **무선 없음** | 품질/보안 감사 현장에서 "무선 모듈 없음"이 오히려 승인 포인트 |
| PoE 옵션, 초소형 | 장비 뒤에 붙이는 크기, 실험실 랜선 하나로 끝 |
| 512MB·저전력 | 텍스트 기록 장치엔 넘치는 사양, 발열 적어 무팬 밀폐 함체 가능 |
| Core SoM 존재 | 양산 시 SoM + 자체 캐리어(MAX3232·DB9·PoE 일체형) |

## 2. 타깃과 팔리는 이유

| 고객 | 지금의 불편 | 박스가 주는 가치 |
|---|---|---|
| 식품 공장(HACCP) | 저울·온도 기록을 감열지 출력해 수기로 장부에 붙임. 감열지 퇴색 | 자동 전자기록, 검색, 출력물 분실 0 |
| 제약·화장품 QC실 | 데이터 무결성(ALCOA+) 요구 강화, 구형 장비는 대응 불가 | 원본 보존 + 타임스탬프 + 위변조 감지 기록 |
| 대학·연구실 | 분석 결과 손으로 옮겨 적다 오기 | 결과가 바로 CSV/엑셀 |
| 소규모 제조 | 장비 알람/로그가 화면에만 뜨고 사라짐 | 장비 이력 블랙박스 |

**한 줄 피치:** "20년 된 장비를 버리지 않고 감사(audit) 통과용 기록을 만든다."

## 3. 장단점

**장점**
1. **"먼저 기록, 해석은 나중"(schema-on-read)**: 장비 포맷을 몰라도 원본 바이트를 전부 저장 → 파서는 나중에 추가/수정해 과거 데이터에도 재적용. 설정 실수로 데이터 잃는 일이 구조적으로 없음.
2. **위변조 감지 로그**: 레코드마다 이전 해시를 포함하는 해시 체인 append-only → 감사 대응 근거.
3. **오프라인 완결**: 서버/인터넷 없이 박스 단독으로 기록·내장 웹 UI 조회 → 망분리 현장 가능.
4. **설치 5분**: 프린터 케이블 빼고 박스 꽂기. 장비 쪽 설정 변경 0 (baudrate 자동 탐지 또는 선택).
5. **장비별 파서 라이브러리 = 누적 자산**: 저울 A사·pH미터 B사 포맷 파서가 쌓일수록 진입장벽.

**단점 (숨기면 안 되는 것)**
1. **"규제 준수"라고 팔 수 없음**: 21 CFR Part 11 / GMP 컴퓨터화 시스템 밸리데이션은 고객 현장에서 하는 절차. 제품은 "준수를 돕는 도구"로만 포지셔닝 — 밸리데이션 문서 패키지 별도 제공 필요할 수 있음.
2. **시계가 생명인데 RTC 백업 전지 없을 수 있음**: 보드 RTC 배터리 지원 여부 **미확인**. 망분리 현장은 NTP도 불가 → 캐리어에 RTC(DS3231급)+코인셀 사실상 필수.
3. **장비 포맷 파편화**: 파서 만들려면 장비별 실물/샘플 출력 필요 → 초반 영업은 사실상 고객 장비별 맞춤 작업.
4. **프린터를 계속 쓰고 싶은 고객**: 박스 뒤로 실제 프린터 pass-through 포트 필요 → HW 약간 복잡.
5. **기존 시장 존재**: 시리얼 데이터 수집/프린터 에뮬레이션 제품은 이미 있을 것(종류·가격 **미확인**, V2에서 조사) → 가격·무결성 기록·오프라인 완결로 차별화해야 함.
6. **인증**: KC 전자파 적합성평가 필요(비용 미확인). 무선 없어서 그나마 단순.

## 4. 제품 구성 (MVP)

```
[레거시 장비] ─ RS-232 ─┬─ MAX3232 ─ UART ─ ROCK Pi S ─ PoE/LAN ─ (선택) 서버·MES
                       └─ pass-through ─ [기존 프린터] (선택)

ROCK Pi S 내부
  capture : 원본 바이트 + 수신 시각 + 해시 체인 → append-only 저장(eMMC 권장)
  parser  : 장비별 플러그인(YAML 정규식 → 필드) → SQLite
  export  : 내장 웹 UI(조회·CSV/엑셀) / MQTT / 공유폴더 드롭
  time    : RTC(DS3231) + NTP(가능 시) / 시각 보정 이벤트도 로그에 기록
```

**설계 원칙**
- 수신 경로(capture)와 해석 경로(parser) 프로세스 분리 — 파서가 크래시해도 기록은 계속.
- 저장소는 eMMC SKU(`RS308-D4E8…`) — SD 마모·감사 신뢰성.
- 정전 대비: 레코드 단위 `fsync` + ext4 `data=journal` 또는 기록 직후 동기화. 쓰기 수명 트레이드오프는 V3에서 측정.

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| V1 수요 | 식품공장 QC 담당·대학 실험실·제약 QC 각 3명 인터뷰: 프린터 출력 장비 몇 대, 기록 어떻게 옮기나 | 장비 3대 이상 현장에서 "구매 의향" 확보 |
| V2 경쟁 | 시리얼 데이터 수집 장비/LIMS 연동 솔루션 가격 조사 | 가격 또는 설치 편의 명확한 우위 |
| V3 기술 | 실제 저울 or pH미터 1대로 캡처·파싱·정전 테스트(전원 강제 차단 100회) | 레코드 손실·손상 0 |
| V4 비용 | 캐리어 보드(MAX3232+RTC+DB9+PoE)·함체·KC 견적 | 목표가 대비 원가율 확인 |
